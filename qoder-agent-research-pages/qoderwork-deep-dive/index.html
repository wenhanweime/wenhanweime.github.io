0. 一句话结论

QoderWork 的「Agent Loop」= renderer 经 tRPC 提交消息 → 主进程 ChatSessionService 队列化 → UnifiedChatExecutor.executeTask 组装一份 Claude-Agent-SDK 风格的 query() options → @qoder-ai/qoder-agent-sdk 通过 ProcessTransport 以 stdio + 行分隔 stream-json 协议 spawn qodercli 二进制 → 主进程 for await 消费事件流 → 投影成 UI 消息 / 落库 / 触发权限确认。qodercli 是一个 Claude Code CLI 形态的 fork（同样的 --print --output-format stream-json --permission-prompt-tool stdio 等参数）。
